# المليونير — Millionaire Party

لعبة مسابقات جماعية لحظية (Next.js + TypeScript + Tailwind + shadcn-style UI). بدون حسابات: اسم مؤقت + رمز غرفة فقط.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run typecheck
npm run test
npm run build
```

## اللعب

1. **أنشئ غرفة** `/create`: اسم + صورة + إعدادات (فئات، صعوبة، عدد الأسئلة، المؤقت، وسائل المساعدة) + بنك أسئلة + وضع الاتصال.
2. **شارك الرمز**: نسخ / رابط `/join/CODE` / QR.
3. **الردهة** `/room/CODE`: استعداد، بنك الأسئلة (المضيف فقط)، لاعبون افتراضيون للتجربة.
4. **اللعب** `/room/CODE/game`: نفس السؤال + نفس المؤقت + كشف متزامن + سلّم جوائز + ترتيب مباشر.
5. **النتائج** `/room/CODE/results`: الفائز والإحصائيات وإعادة اللعب.

## الشبكة (بدون Backend)

- **وضع محلي**: لاعبون افتراضيون + نفس المتصفح. مثالي للتجربة الفورية.
- **وضع P2P** (Trystero/nostr، بدون سيرفر): المضيف هو المرجع (التسلسل، المؤقت `questionEndsAt`، التصحيح). الضيوف لا يستقبلون الإجابة الصحيحة قبل الكشف.
- حدود P2P: ~8–12 لاعباً، وقد يفشل خلف بعض NATs بدون TURN — عندها تظهر رسالة fallback واضحة.
- البنية (`GameTransport` abstraction) جاهزة لإضافة Supabase/Socket.io لاحقاً بدون تغيير منطق اللعبة.

## الأسئلة
- `src/data/questions/batch-{a,b,c}.json`: ~150 سؤالاً عربياً عبر 14 فئة (علوم، تاريخ، جغرافيا، منطق، رياضيات، تقنية، طبيعة، جسم، لغة، الجزائر، عربي، إسلامية، يومية، ذكاء).
- كل سؤال: 4 خيارات + إجابة واحدة صحيحة + شرح.
- الاستيراد (المضيف فقط): XLSX/CSV/JSON → تحليل → تحقق → معاينة → استيراد. انظر `src/lib/bank/`.

## النشر (Vercel)

المشروع static-friendly. اربط الريبو بـ Vercel مع: Framework=Next.js، Build=`npm run build`. لا متغيرات بيئة مطلوبة.

## الجودة

- `npm run typecheck` + `npm run test` + `npm run build` + `npm run lint` قبل كل push.
- هوية بصرية أصلية بالكامل — مفهوم سلّم الجوائز فقط كمفهوم عام، بلا نسخ لأي علامة تلفزيونية.

## الحقوق

- الصور الرمزية: 36 صورة (12 وجوه محايدة + 20 نساء/محجبات/أطفال/كبار سن + 4 رجال ملتحين) بأنماط Notionists وLorelei وOpen Peeps — ملكية عامة CC0 1.0، ملفات PNG محفوظة محلياً في `public/avatars/` لتعمل اللعبة دون إنترنت. إعادة التوليد: `node scripts/generate-avatars.mjs`.
- الأيقونات: Solar Icons (عائلة Bold Duotone) عبر حزمة `solar-icon-set`.
