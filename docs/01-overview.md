# 01 — نظرة عامة

## ما هذا المشروع؟

**المليونير (Millionaire Party)** لعبة مسابقات جماعية لحظية تعمل في المتصفح: غرفة خاصة، رمز قصير، نفس الأسئلة للجميع، نفس المؤقت، سلّم جوائز، وفائز واحد. بلا حسابات وبلا backend.

## المفاهيم الأساسية

| المفهوم | الشرح |
|---|---|
| **الغرفة (Room)** | جلسة خاصة برمز من 5 خانات (مثل `7K4P9`)، يعيش state اللعبة في متصفح المضيف |
| **المضيف (Host)** | منشئ الغرفة؛ الوحيد الذي يضبط الإعدادات، يختار/يرفع بنك الأسئلة، يبدأ اللعبة وينقّل الأسئلة |
| **اللاعب المؤقت** | اسم + صورة رمزية داخل الغرفة فقط؛ لا حساب ولا كلمة مرور ولا تخزين دائم |
| **اللاعب الافتراضي (Bot)** | لاعب محاكى للتجربة الفورية (يجيب بتأخير ونسب ذكاء حسب الصعوبة) |
| **بنك الأسئلة** | مجموعة أسئلة (مدمجة أو مرفوعة) يختارها المضيف قبل البدء ويُقفل تسلسلها عند الانطلاق |
| **المرحلة (Stage)** | جزء من المباراة (تصفيات/سرعة/نصف/رهان/نهائي) بقواعده ومؤقته — انظر `02-gameplay.md` |

## رحلة المضيف

الرئيسية ← إنشاء غرفة (الهوية + المدة + البطولة + الفئات + البنك) ← مشاركة الرمز (نسخ/رابط/QR) ← الردهة (انتظار + استعداد اللاعبين) ← بدء ← إدارة المراحل (التالي/المتابعة) ← النتائج ← إعادة أو غرفة جديدة.

## رحلة اللاعب

الرئيسية ← انضمام (رمز + اسم + صورة) ← الردهة (زر «مستعد») ← الإجابة قبل المؤقت ← الكشف المتزامن ← الصعود/السقوط في الترتيب ← النتيجة النهائية.

## أين يعيش المنطق؟

- **المحرك النقي** (`src/lib/game/engine.ts`): بناء التسلسل، التصحيح، النقاط، الترتيب، التأهل، الرهان — دوال خالصة تُختبر بـvitest.
- **المخزن** (`src/lib/game/store.ts`): حالة الغرفة (Zustand) + أفعال المضيف + محاكاة الـbots.
- **النقل** (`src/lib/net/p2p.tsx` + bots): إيصال الحالة؛ أي backend مستقبلي = محوّل جديد فقط.
- **القاعدة الذهبية**: المضيف هو المرجع — لا تُصدَّق ساعات المتصفح ولا نقاط العميل، ولا يُرسَل `correctAnswer` قبل الكشف.
