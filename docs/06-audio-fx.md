# 06 — الصوت والاهتزاز والمؤثرات

## محرك الصوت (`src/lib/fx/audio.ts`)

WebAudio مُصنّع بالكامل — **صفر ملفات صوتية**، يعمل دون إنترنت، ويُفعَّل بأول لمسة (سياسة المتصفح):

| الحدث | الصوت |
|---|---|
| نقر زر | نقرة مزدوجة الطبقة (tick + thump) |
| لمس إجابة | tick مميز، ثم صوت قفل "clunk" عند التأكيد |
| صحيحة | arpeggio خماسي + وميض + حشد؛ السلسلة ترفع الطبقة (`streak`) |
| خاطئة | "braam" سينمائي هابط + صدمة |
| عدّ تنازلي | tick متسارع آخر 10 ثوانٍ + نبض قلب تحت 3 |
| تجاوز نقطة أمان | fanfare كامل (يُحجز لها فقط) |
| مراحل/فوز | بوق المراحل، لحن التتويج، موسيقى تتوتر في نصف النهائي والنهائي |

## الاهتزاز (`src/lib/fx/haptics.ts`)

أنماط سينمائية (قفل مزدوج، نبض قلب، دويّ، إيقاع تتويج) عبر `navigator.vibrate` مع فحص الدعم — بلا أثر على سطح المكتب.

## الشدة: درامي / هادئ

`millionaire:intensity` في `/settings`: **الوضع الهادئ** يختزل كل صوت لنغمة أحادية وكل اهتزاز لنقرة واحدة — مع مفاتيح مستقلة للصوت والموسيقى والاهتزاز والحركة.

## المؤثرات البصرية

حجاب 3-2-1 قبل الكشف، توهج أخضر نابض للصحيح، اهتزاز شاشة للخطأ، مكسب `+X` يطير نحو الرصيد، شارة سلسلة نارية، خلفية النهائي الذهبية، confetti canvas خفيف، عدّاد متصاعد — كلها CSS/Canvas بلا مكتبات، وتحترم تقليل الحركة.

## قابلية الاختبار

`countdownPlan` (تخطيط النغمات) و`patternFor` (أنماط الاهتزاز) دوال خالصة تُختبر في `src/lib/fx/fx.test.ts`.
