## سكيما السؤال

```ts
{ id, question, answers: [4], correctAnswer: 0..3,
  category, difficulty: easy|medium|hard|expert,
  explanation, tags? }
```

## معايير الجودة (تُطبق على كل دفعة)

- إجابة واحدة قاطعة، مشتتات معقولة، توازن مواضع الصحيح (~25% لكل موضع).
- لا مشاهير/غناء/نميمة؛ لا حقائق متطايرة (أعداد سكان لحظية)؛ الأسئلة الزمنية مؤرخة.
- كل تاريخ/رقم/اسم **يُتحقق بالبحث الحي** — المشكوك فيه يُحذف لا يُخمَّن.
- مراجعة متقاطعة للفئات الحساسة (الجزائر، الشرق الأوسط، التاريخ).

## حقائق حساسة مثبتة (لا تغيّرها من الذاكرة)

- **ولايات الجزائر: 69** (القانون 26-06، الجريدة الرسمية أفريل 2026؛ 11 ولاية جديدة 59–69).
- تمنراست الأكبر مساحة (~557,906 كم²)؛ تاهات الأعلى (بدون رقم متنازع عليه في الشرح).
- تسمية الفئة الجغرافية: **الشرق الأوسط** (لا إطار عرقي)؛ أسئلة المغرب الكبير في **شمال إفريقيا**.

## استيراد المضيف (XLSX/CSV/JSON)

التدفق: **رفع ← تحليل ← تحقق ← معاينة ← استيراد** (`src/lib/bank/parse.ts` + `validate.ts` + `BankManager.tsx`). يُقبل `question/answers/correctAnswer/category/difficulty` مع ترويسات عربية مرنة (السؤال، الإجابة الصحيحة، الصعوبة…)، ويُرفض التكرار والناقص مع تقرير أخطاء. بنك اللعبة الجارية **مقفل** — الرفع أثناء اللعب لا يؤثر إلا على مباراة قادمة.

## الحارس الآلي (`dataset.test.ts`)

يفحص: السكيما الكاملة، فرادة المعرفات والنصوص، ≥80 سؤالاً/فئة، توازن المواضع (18–32%)، وغياب فئة `arab` القديمة. أي دفعة مكسورة تُرفض قبل الدمج.
