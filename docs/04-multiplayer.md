# 04 — اللعب الجماعي والعدالة (بدون Backend)

## الوضعان

- **محلي**: نفس المتصفح + لاعبون افتراضيون (bots بذكاء وتأخير واقعيين) — تجربة فورية واختبار.
- **P2P حقيقي** (`src/lib/net/p2p.tsx` عبر Trystero/nostr): الغرفة = رمز Trystero، بلا أي سيرفر نكتبه. يعمل على Vercel مباشرة.

## المضيف هو المرجع (Host-authoritative)

- التسلسل، `questionEndsAt`، التصحيح، النقاط، الكشف — كلها من مسار المضيف (`store.ts` + `engine.ts`).
- الضيوف يستقبلون السؤال **بدون** `correctAnswer`؛ الكشف حدث منفصل متزامن.
- المؤقت يُحسب من `questionEndsAt` الصادر عن المضيف — لا ثقة بساعات المتصفح.
- انقطاع المضيف = تجميد واضح + هجرة القيادة لأقدم peer (مصمم في المحرك).

## حدود P2P بصراحة

- عملي حتى ~8–12 لاعباً (شبكة mesh) — مثالي للغرف الخاصة.
- قد يفشل خلف بعض NATs بدون TURN — رسالة fallback واضحة، والوضع المحلي بديل دائم.
- البنية تجريدية (`GameTransport`): Supabase Realtime أو Socket.io لاحقاً = محوّل جديد فقط.

## أوضاع مستقبلية (البنية جاهزة)

سرعة، فرق، إقصاء، بطولات — `StageKind` و`buildStages` قابلان للتوسعة دون كسر الوضع الحالي.
